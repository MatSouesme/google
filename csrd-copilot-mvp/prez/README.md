### 2. **schneider_electric_csrd_page.html**
Page web personnalisée exemple pour Schneider Electric, démontrant notre stratégie GTM d'Account-Based Marketing (ABM).

**Caractéristiques:**
- Hyper-personnalisée avec données réelles de Schneider
- Design premium (Schneider brand colors)
- Calculs ROI spécifiques (€370K savings, 4.6x ROI)
- Workflow adapté à leurs systèmes (SAP, Workday, EcoVadis)
- Entièrement responsive et animé

**Usage:**
- **Option A**: Ouvrir dans un navigateur pour voir le rendu complet
- **Option B**: Prendre des screenshots pour inclure dans le slide 10 (GTM Strategy)
- **Option C**: Demo live pendant la présentation (15-20 secondes)

**Comment visualiser:**
```bash
# Ouvrir dans votre navigateur par défaut
start schneider_electric_csrd_page.html    # Windows
open schneider_electric_csrd_page.html     # Mac
xdg-open schneider_electric_csrd_page.html # Linux
```

## 🎯 Comment Utiliser Ces Matériaux

### Pour créer le Pitch Deck (20 février)

1. **Lire PITCH_DECK_CONTENT.md**
   - Comprendre la structure complète (16 slides)
   - Noter les slides clés (nouveaux: 9.5, modifications: 10, 11)

2. **Créer les slides visuelles**
   - Outils suggérés: PowerPoint, Google Slides, Keynote, Figma
   - Suivre les design guidelines (couleurs, typo)
   - Max 3-4 bullets per slide (keep it visual)

3. **Intégrer la page Schneider Electric**
   - Screenshot du hero section pour le slide 10
   - Ou inclure en annexe du PDF

4. **Export final**
   - Format: PDF pour soumission
   - Backup: PPTX/Google Slides pour modifications

### Pour le Live Pitch (27 février - 10 min + 5 Q&A)

1. **Préparer le script oral**
   - Utiliser le timing recommandé dans PITCH_DECK_CONTENT.md
   - Répéter pour tenir les 10 minutes

2. **Démo optionnelle**
   - Si connexion internet disponible: montrer la page Schneider (15 sec)
   - Sinon: utiliser des screenshots dans les slides

3. **Q&A Prep**
   - Relire BUSINESS_ANALYSIS.md pour maîtriser les détails
   - Préparer des réponses pour:
     * "Qui sont vos compétiteurs?" → Sweep, Greenly, Legacy GRC (slide 9.5)
     * "Quelle est la taille du marché?" → TAM/SAM/SOM (slide 7)
     * "Comment allez-vous acquérir des clients?" → GTM custom pages (slide 10)
     * "Pourquoi maintenant?" → CSRD mandatory 2024 (slide 3, 12)

## 🎨 Design Guidelines Recap

### Couleurs
- **Vert primaire**: #40695B (forest green, sustainability)
- **Bleu secondaire**: #277884 (deep teal, trust/tech)
- **Accent**: #F39C12 (gold, premium)
- **Texte**: #2C2C2C (charcoal), #FFFFFF (white)

### Typographie
- **Titres**: Arial Bold, 36-44pt
- **Corps**: Arial Regular, 18-24pt
- **Chiffres impactants**: Arial Bold, 60-80pt

### Layout
- Minimal text (max 3-4 bullets)
- Large breathing space
- High contrast
- Icons > text
