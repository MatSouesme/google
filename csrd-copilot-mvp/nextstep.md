**Strategy:** "Wizard of Oz".

- [ ] Add a step before the CSV Upload.
- [ ] Create a list of toggles:

- [ ] Store this selection in the React State (`selectedStandards`).

### 1.2 The "Fake" XBRL/ESEF Export (Backend + Frontend)
*File: `backend/api/main.py` & `frontend/src/pages/ReportViewer.jsx`*
**Goal:** Prove we understand the legal requirement (XBRL tagging) without coding a real XML parser.
- [ ] **Backend:** Create endpoint `GET /export-xbrl/{report_id}`.
    -   Action: Returns a dummy `.zip` file named `ESEF_Package_{date}.zip`.
    -   Content: Can just contain a dummy `report.html` and `taxonomy.json`.
- [ ] **Frontend:** Add a button `[🏷️ Export XBRL Package]` next to the PDF Export.
- [ ] **Interaction:** On click -> Show a spinner "Mapping datapoints to ESEF Taxonomy..." (Wait 2s) -> Trigger Download -> Show Success Toast "XBRL Tagging Complete".
